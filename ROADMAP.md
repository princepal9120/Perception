# Roadmap

## Current OSS MVP

- local-first setup without Clerk
- configurable auth modes: disabled, jwt, clerk
- configurable providers for chat model, embeddings, and search
- Deep Research as the primary showcase workflow
- contributor docs and CI

## Next

- save and reopen Deep Research reports
- better local-model templates for Ollama / LM Studio / vLLM
- settings UI for provider selection
- cleaner JWT-mode user flows on the frontend
- stronger document-ingestion smoke coverage

## Explicitly deferred

- full plugin ecosystem
- broad vector database abstraction
- broad voice-provider abstraction
- pricing, subscriptions, and team-workspace product features
